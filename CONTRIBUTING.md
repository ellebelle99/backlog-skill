# Contributing

Thanks for wanting to improve this skill. It is maintained by Andreas Ellegaard Andersen, who reviews every change before it goes in.

## What fits

The skill has one job: capture, list and prioritize ideas in a single `BACKLOG.md`. 
It never executes the items. Changes that keep that job small and fast are welcome, such as clearer wording, a missing edge case or a fix for a subcommand that misbehaves.

Changes that turn it into a task runner, add per-folder backlogs or make capture slower are unlikely to be accepted.

## How to propose a change

1. Open an issue first for anything bigger than a typo, so we can agree it fits.
2. Fork the repository and create a branch.
3. Edit `skills/backlog/SKILL.md`.
4. Try the changed subcommands by hand in Claude Code.
5. Open a pull request and fill in the template.

## Testing

A skill is instructions, not code, so there is no automated test run. Say in the pull request which commands you tried and what happened.

## Conduct

Be respectful. Threads that are not may be closed.
