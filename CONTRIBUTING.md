# Contributing

Thanks for wanting to improve this skill.

It is maintained by Andreas Ellegaard Andersen, who reviews every change before it goes in.


## What fits

The skill has one job: capture, list and prioritize ideas in a single `BACKLOG.md`. It never executes the items.

Welcome: clearer wording, a missing edge case, a fix for a subcommand that misbehaves.

Unlikely to be accepted: anything that turns it into a task runner, adds per-folder backlogs or makes capture slower.


## How to propose a change

1. Open an issue first for anything bigger than a typo.
2. Fork the repository and create a branch.
3. Edit `skills/backlog/SKILL.md`.
4. Try the changed subcommands in Claude Code.
5. Open a pull request, and say which commands you tried and what happened.

A skill is instructions, not code, so there is no automated test run.


## Conduct

Be respectful. Threads that are not may be closed.
